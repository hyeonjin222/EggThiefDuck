## 📝 한 줄 요약
**장르**: 탑뷰 트윈스틱 슈팅 + 웨이브 생존  
**제작 기간**: 3주 (진행 중)  
**사용 기술**: Unreal Engine 5.6.1 / C++ 20  
**개발 인원**: 1인 개발

## 🚀 핵심 기능 (Key Features)
1. **데이터 기반 무기 시너지 (Mutation System)**  
   - `UUpgradeDataAsset`을 활용해 하드코딩 없이 무기 성능(연사력, 관통, 탄퍼짐 등)을 실시간 중첩.
   - 기관총(연사) + 저격총(관통/데미지) 등 서로 다른 무기 특성이 곱셈 누적되어 수천 가지 조합 가능.
2. **C++ 기반 '호핑(Hopping)' 애니메이션**  
   - Skeletal Mesh와 애니메이션 에셋 없이 **스쿼시 앤 스트레치(Squash & Stretch)** 기법을 순수 코드로 구현.
   - 적들의 리듬감 있는 통통 튀는 움직임과 피격 시 젤리 같은 물리 반응을 실시간 연산으로 처리.
3. **지능형 웨이브 & 시간 시스템**  
   - 24시간 실시간 낮밤 사이클과 그에 따른 조명/페이즈 전환(전투/정비) 자동화.
   - 플레이어 주변 1200~1800 유닛 외곽에서 가중치 기반으로 적을 생성하는 '도넛형 스폰' 로직 구축.

## 🛠 내가 직접 만든 부분 (C++ 100%)
- **게임 아키텍처**: `GameMode`, `PlayerController`, `Character` 간의 체계적인 상태 관리 및 이벤트 브릿지 설계.
- **전투 시스템**: 과열 메커니즘이 포함된 탄창 시스템, 투사체 풀링 최적화, 관통/폭발 로직.
- **UI 시스템**: `meta = (BindWidget)`을 이용해 C++에서 직접 위젯 컴포넌트를 제어하여 성능 최적화 및 로직 분리.
- **환경 연출**: 쿼터니언 Slerp 보간을 이용한 물리 기반 태양 궤도 계산 및 심리스 인트로 시스템.

## 🔥 기술적 도전 및 해결
**문제**: 관통(Piercing) 투사체 구현 시, 한 프레임에 동일한 적에게 중복 데미지가 들어가거나 관통 횟수 계산이 꼬이는 문제 발생.  
**해결**: 투사체 클래스 내부에 `TSet<AActor*> HitActors` 목록을 생성하여 이미 타격한 대상을 추적하고, `MaxPiercingCount`를 넘어서는 즉시 투사체를 소멸시키는 엄격한 상태 체크 로직 도입.  
**배움**: 고속으로 이동하는 액터의 상태 관리는 프레임 단위의 이벤트보다 데이터 중심의 명확한 검증 단계가 필수적임을 깨달음.
